# 🛒 Ma liste de courses — Starter

Mini-projet Next.js pour pratiquer Redux Toolkit.

## Setup

```bash
git clone https://github.com/Yipno/grocery-list.git
cd grocery-redux
yarn
yarn dev
```

Ouvre [http://localhost:3001](http://localhost:3001) dans ton navigateur.

Tu dois voir un formulaire et la liste vide. Les boutons font des `console.log` pour l'instant — c'est à toi de les connecter à Redux !

## Stack

- Next.js (pages router)
- React
- Redux Toolkit + react-redux

## À faire

Cherche les `// TODO Redux:` dans les fichiers existants :

- `pages/_app.js`
- `components/AddItemForm.js`
- `components/GroceryList.js`

Et **crée** le fichier `reducers/groceries.js` from scratch.

> tu peux installer l'extension **Redux DevTools** dans ton navigateur, ça t'aidera énormément à débugger.

Bon courage !
